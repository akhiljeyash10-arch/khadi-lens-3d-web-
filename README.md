# KHADI — BEYOND THE SURFACE
### Interactive 3D Cinematic Textile Authentication Platform

> **"Don't judge the fabric by how it looks. Measure how it was made."**

A high-fidelity, interactive 3D WebGL and scrollytelling web experience presenting a portable optical measurement system that examines the physical structure of finished fabric to assess authenticity and detect mill-made adulteration.

---

## ✨ Features

- **Cinematic Scrollytelling Engine**: Synchronized 432-frame optical sequence scrub with adaptive high-DPI canvas rendering.
- **Interactive 3D Photometric Topography**: Three.js WebGL procedural micro-fiber mesh viewer with real-time 360° grazing light azimuth control and normal shader inspection.
- **Directional Illumination Simulator**: Interactive quad-directional LED dial demonstrating 45° elevation cast-shadow separation.
- **Comparative Scientific Lens**: Multi-layer inspection mode comparing handcrafted Khadi against machine-made imitations across Optical RGB, 3D Normal Map, and 2D FFT spectral periodicity.
- **Scientific Consistency Report**: Explainable assessment dashboard with Gaussian reference distribution curves and polar anisotropy radar plots.
- **Multi-Plane 3D Parallax Architecture**: Multi-speed scroll depth planes (`0.35x` background watermark, `1.0x` midground cards, `1.5x` floating telemetry chips), interactive 3D cursor tilt cards, and ambient floating optical micro-fibers.

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS
- **3D & WebGL**: Three.js
- **Animations**: GSAP 3 (ScrollTrigger)
- **Smooth Scroll**: Lenis
- **Icons**: Lucide React

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/akhiljeyash10-arch/khadi-lens-3d-web-.git
   cd khadi-lens-3d-web-
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
